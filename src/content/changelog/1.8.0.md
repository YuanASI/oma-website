## Features
- **Checkpoint and resume** ([#294](https://github.com/open-multi-agent/open-multi-agent/issues/294) by [@mvanhorn](https://github.com/mvanhorn), [#314](https://github.com/open-multi-agent/open-multi-agent/issues/314) by [@JackChen-me](https://github.com/JackChen-me)). A long run can now survive a crash or restart. Persist progress to any `MemoryStore` with `checkpoint: true` on `runTeam` / `runTasks` / `runFromPlan`, then resume with `orchestrator.restore(...)`. On resume, `runTeam` re-runs coordinator synthesis so you still get a final answer, and checkpointing into the team's own shared-memory store no longer re-serializes the whole store per task.
- **Consensus verification reaches runTeam** ([#301](https://github.com/open-multi-agent/open-multi-agent/issues/301) by [@nuthalapativarun](https://github.com/nuthalapativarun)). The per-task judge loop from 1.7.0 now applies to coordinator-generated tasks. Pass the judges with `RunTeamOptions.verifyJudges`, and the coordinator opts a task in with `verify: true` or a partial config.
- **Native reasoning round-trip on Bedrock** ([#302](https://github.com/open-multi-agent/open-multi-agent/issues/302) by [@nuthalapativarun](https://github.com/nuthalapativarun)). Extended-thinking blocks round-trip through Bedrock's signature protocol with full fidelity, moving `echoesReasoning` from `never` to `own-issued`.

## Fixes
- Dashboard: the run details panel is back to a right-hand sidebar on desktop instead of stacking under the canvas ([#308](https://github.com/open-multi-agent/open-multi-agent/issues/308) by [@JackChen-me](https://github.com/JackChen-me)).

## Onboarding and examples
- `npm create oma-app` scaffolds a runnable multi-agent demo in one command ([#305](https://github.com/open-multi-agent/open-multi-agent/issues/305), [#306](https://github.com/open-multi-agent/open-multi-agent/issues/306) by [@JackChen-me](https://github.com/JackChen-me)).
- The full-app examples run end to end on a single DeepSeek key ([#311](https://github.com/open-multi-agent/open-multi-agent/issues/311) by [@JackChen-me](https://github.com/JackChen-me)).
- New consensus pattern example ([#297](https://github.com/open-multi-agent/open-multi-agent/issues/297) by [@nuthalapativarun](https://github.com/nuthalapativarun)).
