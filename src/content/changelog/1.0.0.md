## What's new since 0.2.0

### Features
- **Structured output** — optional `outputSchema` (Zod) on any agent, with auto-retry on validation failure ([#36](https://github.com/open-multi-agent/open-multi-agent/issues/36), [#38](https://github.com/open-multi-agent/open-multi-agent/issues/38))
- **Task retry with exponential backoff** — `maxRetries`, `retryDelayMs`, `retryBackoff` per task ([#37](https://github.com/open-multi-agent/open-multi-agent/issues/37))
- **Observability** — `onTrace` callback emits structured spans for LLM calls, tool calls, tasks, and agent runs ([#40](https://github.com/open-multi-agent/open-multi-agent/issues/40))
- **Lifecycle hooks** — `beforeRun` / `afterRun` on AgentConfig for prompt rewriting and result post-processing ([#45](https://github.com/open-multi-agent/open-multi-agent/issues/45))
- **Human-in-the-loop** — `onApproval` callback between task execution rounds to gate the next batch ([#46](https://github.com/open-multi-agent/open-multi-agent/issues/46))
- **Loop detection** — detects stuck agents repeating the same tool calls or text, with configurable `warn` / `terminate` / custom handler ([#49](https://github.com/open-multi-agent/open-multi-agent/issues/49))
- **Grok (xAI) adapter** — first-class support with dedicated GrokAdapter ([#44](https://github.com/open-multi-agent/open-multi-agent/issues/44))
- **Fallback tool-call extraction** — local models that emit tool calls as plain text are now handled automatically ([#47](https://github.com/open-multi-agent/open-multi-agent/issues/47))

### Testing & quality
- 340 tests, 71% line coverage across `src/` ([#53](https://github.com/open-multi-agent/open-multi-agent/issues/53))
- Coverage badge added to README ([#55](https://github.com/open-multi-agent/open-multi-agent/issues/55))
