## Features

### Streaming reasoning events
`StreamEvent` now supports a `reasoning` type that carries the model's thinking tokens in real time. `ReasoningBlock` is also added to the `ContentBlock` union for non-streaming paths. Supported on Anthropic and OpenAI providers. ([#174](https://github.com/open-multi-agent/open-multi-agent/issues/174) by [@SiMinus](https://github.com/SiMinus))

### `onAgentStream` and `onPlanReady` hooks
Two new orchestrator hooks (runTeam only): `onAgentStream` delivers real-time per-token streaming events during agent runs, and `onPlanReady` fires after the coordinator decomposes the goal into a task DAG -- return `false` to abort before any agent work starts. ([#182](https://github.com/open-multi-agent/open-multi-agent/issues/182), [#181](https://github.com/open-multi-agent/open-multi-agent/issues/181) by [@tizerluo](https://github.com/tizerluo); [#184](https://github.com/open-multi-agent/open-multi-agent/issues/184), [#183](https://github.com/open-multi-agent/open-multi-agent/issues/183) by [@JackChen-me](https://github.com/JackChen-me))

### Agent Observation Pipeline: new trace events
`plan_ready` and `agent_stream` trace events join the trace pipeline, enabling downstream observers to react to plan generation and streaming agent output. ([#188](https://github.com/open-multi-agent/open-multi-agent/issues/188) by [@ibrahimkzmv](https://github.com/ibrahimkzmv))

### AWS Bedrock adapter
New LLM adapter for Amazon Bedrock, supporting the full adapter contract (chat + stream). ([#194](https://github.com/open-multi-agent/open-multi-agent/issues/194) by [@CodingBangboo](https://github.com/CodingBangboo))

### ToolCallTrace includes input/output
`ToolCallTrace` now carries the tool's input and output payloads, making it useful for debugging and audit without inspecting the raw conversation. ([#124](https://github.com/open-multi-agent/open-multi-agent/issues/124) by [@MyPrototypeWhat](https://github.com/MyPrototypeWhat))

## Fixes

- Strip image blocks before summarize compression to avoid ballooning token cost. ([#196](https://github.com/open-multi-agent/open-multi-agent/issues/196) by [@MyPrototypeWhat](https://github.com/MyPrototypeWhat))
- Preserve `tool_use`/`tool_result` pairing during sliding-window truncation, fixing orphaned tool blocks. ([#193](https://github.com/open-multi-agent/open-multi-agent/issues/193) by [@MyPrototypeWhat](https://github.com/MyPrototypeWhat))
- `onAgentStream` path now forwards the full `RunOptions` into the streaming runner so `onTrace`, delegation, and run metadata work during streaming. ([#184](https://github.com/open-multi-agent/open-multi-agent/issues/184) by [@JackChen-me](https://github.com/JackChen-me))
- `onPlanReady` abort path now reports the real coordinator token cost instead of zero, and catches thrown callbacks. ([#183](https://github.com/open-multi-agent/open-multi-agent/issues/183) by [@JackChen-me](https://github.com/JackChen-me))

## Examples

- Express customer support pipeline: multi-agent triage, routing, and resolution. ([#191](https://github.com/open-multi-agent/open-multi-agent/issues/191) by [@CodingBangboo](https://github.com/CodingBangboo))
- Personalized interview simulator: dynamic question generation with structured output. ([#189](https://github.com/open-multi-agent/open-multi-agent/issues/189) by [@mmjwxbc](https://github.com/mmjwxbc))
- Incident postmortem DAG: reconstruct timeline from logs and deploys. ([#187](https://github.com/open-multi-agent/open-multi-agent/issues/187) by [@binghuaren96](https://github.com/binghuaren96))
