## v1.4.2

Drop-in safe patch: three opt-in additions and three new examples. All new APIs default to off.

### New (opt-in)

- **`RunTeamOptions.revealCoordinator`** ([#245](https://github.com/open-multi-agent/open-multi-agent/issues/245) by [@JackChen-me](https://github.com/JackChen-me)). When `true`, prepends a team-context block (goal, full roster, this worker's assignee identity) to every worker prompt under `runTeam`. Default `false` keeps existing prompts byte-identical. `runTasks` and the short-circuit single-agent path ignore it. Closes [#244](https://github.com/open-multi-agent/open-multi-agent/issues/244).
- **`enableReasoningTextReplay`** ([#234](https://github.com/open-multi-agent/open-multi-agent/issues/234) by [@matthewYang08](https://github.com/matthewYang08)). Opt-in replay of framework `reasoning` blocks as inline `<thinking>` text on OpenAI-family requests, capped by `maxReasoningReplayChars` (default 1200). Also closes a latent 400 against OpenAI when a reasoning-only assistant message emitted `{content: null}` with no `tool_calls`. Refs [#223](https://github.com/open-multi-agent/open-multi-agent/issues/223).
- **`ReasoningBlock.provenance` + `LLMAdapter.capabilities`** ([#243](https://github.com/open-multi-agent/open-multi-agent/issues/243) by [@MyPrototypeWhat](https://github.com/MyPrototypeWhat)). Phase 1 of [#223](https://github.com/open-multi-agent/open-multi-agent/issues/223): additive IR fields, per-adapter `echoesReasoning: 'never' | 'own-issued'` declarations, and a shared `reasoningBlockToInlineText` helper. No behavior change yet; Phase 2 wires `capabilities` into the outbound fallback.
