## open-multi-agent v1.5.0

### Features

- **Per-agent filesystem sandbox** ([#264](https://github.com/open-multi-agent/open-multi-agent/issues/264) by [@JackChen-me](https://github.com/JackChen-me)). `file_read/file_write/file_edit/grep/glob`
  now resolve every path, symlinks included, inside each agent's `cwd`, defaulting to
  `<cwd>/.agent-workspace`. `bash` stays unsandboxed. Behavior change below.
- **Cross-provider reasoning text fallback** ([#260](https://github.com/open-multi-agent/open-multi-agent/issues/260) by [@MyPrototypeWhat](https://github.com/MyPrototypeWhat)). `preserveReasoningAsText`
  carries reasoning across providers that can't echo native reasoning blocks, as inline
  `<thinking>` text instead of dropping it. Phase 2 of [#223](https://github.com/open-multi-agent/open-multi-agent/issues/223).
- **MiMo provider** ([#265](https://github.com/open-multi-agent/open-multi-agent/issues/265) by [@kidoom](https://github.com/kidoom)).
- **Doubao (Volcengine) provider shortcut** ([#261](https://github.com/open-multi-agent/open-multi-agent/issues/261) by [@kidoom](https://github.com/kidoom), [#236](https://github.com/open-multi-agent/open-multi-agent/issues/236) by [@janelawrence](https://github.com/janelawrence)). Target
  Doubao models without custom `baseURL` wiring.
- **DeepSeek V4 default model names** ([#250](https://github.com/open-multi-agent/open-multi-agent/issues/250) by [@JackChen-me](https://github.com/JackChen-me)). Behavior change below.

### Fixes

- **Secrets redacted from traces, bash output, and dashboard payloads** ([#263](https://github.com/open-multi-agent/open-multi-agent/issues/263) by [@JackChen-me](https://github.com/JackChen-me)).
  API keys and tokens no longer leak into observability surfaces.
- **MCP: dedupe normalized tool names, clean up client/transport on connect failure**
  ([#256](https://github.com/open-multi-agent/open-multi-agent/issues/256) by [@JackChen-me](https://github.com/JackChen-me)).
- **Orchestrator honors `abortSignal` before synthesis and rejects ambiguous task deps**
  ([#255](https://github.com/open-multi-agent/open-multi-agent/issues/255) by [@JackChen-me](https://github.com/JackChen-me)).
- **Loop detector replays history and warns on text-only loops** ([#254](https://github.com/open-multi-agent/open-multi-agent/issues/254) by [@JackChen-me](https://github.com/JackChen-me)).
- **DeepSeek echoes `reasoning_content` on V4 tool-calling** ([#251](https://github.com/open-multi-agent/open-multi-agent/issues/251) by [@JackChen-me](https://github.com/JackChen-me)).

### Behavior changes

- **Filesystem tools sandbox to `<cwd>/.agent-workspace` by default** ([#264](https://github.com/open-multi-agent/open-multi-agent/issues/264)). Agents that read or
  wrote outside `process.cwd()`, or used relative paths, now get a sandbox error. Set
  `OrchestratorConfig.defaultCwd` (or `AgentConfig.cwd`) to your root, `process.cwd()` for the old
  wide default, or `null` to disable. `bash` is not sandboxed.
- **DeepSeek CLI default is now `deepseek-v4-flash`** ([#250](https://github.com/open-multi-agent/open-multi-agent/issues/250)). Affects the `oma` CLI run without
  `--model`; library users are unaffected (no hardcoded default in the adapter). `deepseek-chat`
  and `deepseek-reasoner` keep routing until DeepSeek retires them on 2026-07-24.

### Package metadata

- **`docs/` no longer ships in the npm tarball.** README links now point to the GitHub copy, so
  they always track the latest version. If you read docs from
  `node_modules/@open-multi-agent/core/docs/` (uncommon), switch to the GitHub URLs.
