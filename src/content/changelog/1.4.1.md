## v1.4.1

Patch release: two bug fixes for OpenAI-family adapters and the runner, plus Vercel AI SDK as an optional adapter. The previous npm package (`@jackchen_me/open-multi-agent`) is now formally deprecated.

### Bug fixes
- **OpenAI-family adapters: guard `choices[0]` with optional chaining** ([#220](https://github.com/open-multi-agent/open-multi-agent/issues/220)). Prevents crashes when providers return empty `choices` arrays. Thanks [@dvirarad](https://github.com/dvirarad).
- **Runner: defer `maxTokenBudget` break until after `tool_result` is appended** ([#221](https://github.com/open-multi-agent/open-multi-agent/issues/221)). Fixes orphaned `tool_use` blocks when the token budget is hit mid-turn. Thanks [@CodingBangboo](https://github.com/CodingBangboo).

### New (optional)
- **Vercel AI SDK adapter** via the dedicated `@open-multi-agent/core/ai-sdk` subpath ([#229](https://github.com/open-multi-agent/open-multi-agent/issues/229)). Bridges `LLMAdapter` to AI SDK's `generateText` / `streamText`. Optional peer dep `ai`; main import is unaffected if you don't use it. Thanks [@ibrahimkzmv](https://github.com/ibrahimkzmv).

### Documentation
- MiniMax provider community offer and setup guide ([#219](https://github.com/open-multi-agent/open-multi-agent/issues/219)).
- Label hero GIF as post-run replay ([#222](https://github.com/open-multi-agent/open-multi-agent/issues/222)).

### Deprecation
- The previous npm package, `@jackchen_me/open-multi-agent`, is now formally deprecated. Existing installs continue to work; new installs should use `npm install @open-multi-agent/core`. The npm CLI shows a deprecation message automatically.
