## Features
- Replay persisted team plans, so a previously decomposed plan can be re-run without a new coordinator pass ([#285](https://github.com/open-multi-agent/open-multi-agent/issues/285) by [@cat0825](https://github.com/cat0825))
- Add a Tencent Hunyuan provider adapter ([#281](https://github.com/open-multi-agent/open-multi-agent/issues/281) by [@KaitlynFeng](https://github.com/KaitlynFeng))
- Add a robust regex fallback for malformed single-string JSON tool calls from local models ([#269](https://github.com/open-multi-agent/open-multi-agent/issues/269) by [@apollo-mg](https://github.com/apollo-mg))

## Fixes
- Validate message content at every adapter entry, surfacing a clear InvalidMessageError instead of a deep `content.some is not a function` crash ([#288](https://github.com/open-multi-agent/open-multi-agent/issues/288) by [@JackChen-me](https://github.com/JackChen-me), implementing the fail-fast approach [@apollo-mg](https://github.com/apollo-mg) diagnosed in [#268](https://github.com/open-multi-agent/open-multi-agent/issues/268))
- Preserve memoryScope and retry config when a plan is replayed ([#287](https://github.com/open-multi-agent/open-multi-agent/issues/287) by [@JackChen-me](https://github.com/JackChen-me))
- Support structured shared-memory handoff between agents ([#284](https://github.com/open-multi-agent/open-multi-agent/issues/284) by [@cat0825](https://github.com/cat0825))

## Internal
- Extract a shared repairToolArgs helper across the OpenAI-compatible adapters ([#282](https://github.com/open-multi-agent/open-multi-agent/issues/282) by [@JackChen-me](https://github.com/JackChen-me))
- Add unit tests for the error types ([#290](https://github.com/open-multi-agent/open-multi-agent/issues/290) by [@Oxygen56](https://github.com/Oxygen56))

## Docs
- Move the Ecosystem section above Examples in the README ([#277](https://github.com/open-multi-agent/open-multi-agent/issues/277) by [@JackChen-me](https://github.com/JackChen-me))

npm install @open-multi-agent/core@1.6.0
