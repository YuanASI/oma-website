First minor release since 1.1.0. MCP integration, three new LLM providers, context management strategies, a CLI, tool output cost controls, and fixes for abort and error propagation.

### Features

- **MCP integration.** New `connectMCPTools()` wires any MCP server (stdio) directly into agent tool use. `@modelcontextprotocol/sdk` is an optional peer dependency. Runnable example at `examples/16-mcp-github.ts`. ([#89](https://github.com/open-multi-agent/open-multi-agent/issues/89), by [@ibrahimkzmv](https://github.com/ibrahimkzmv))

- **Three new LLM providers.** First-class `provider: 'deepseek'` (`deepseek-chat`, `deepseek-reasoner`), `provider: 'minimax'` (global and China endpoints via `MINIMAX_BASE_URL`), and verified Groq via OpenAI-compatible `baseURL` in `examples/19-groq.ts`. ([#113](https://github.com/open-multi-agent/open-multi-agent/issues/113) and [#114](https://github.com/open-multi-agent/open-multi-agent/issues/114) by [@hkalex](https://github.com/hkalex); [#121](https://github.com/open-multi-agent/open-multi-agent/issues/121) by [@mvanhorn](https://github.com/mvanhorn))

- **Context management strategies.** New `AgentConfig.contextStrategy` keeps long runs under token ceilings with four strategies: `sliding-window`, `summarize`, `compact` (rule-based, no extra LLM call), and `custom`. ([#88](https://github.com/open-multi-agent/open-multi-agent/issues/88) by [@ibrahimkzmv](https://github.com/ibrahimkzmv); [#111](https://github.com/open-multi-agent/open-multi-agent/issues/111), [#119](https://github.com/open-multi-agent/open-multi-agent/issues/119) by [@JackChen-me](https://github.com/JackChen-me))

- **Tool output cost controls.** New `AgentConfig.maxToolOutputChars` and per-tool `ToolDefinition.maxOutputChars` truncate large outputs (head + tail with a marker). New `AgentConfig.compressToolResults` compresses older tool results once the agent has moved on; errors are never compressed. ([#110](https://github.com/open-multi-agent/open-multi-agent/issues/110), [#115](https://github.com/open-multi-agent/open-multi-agent/issues/115), [#116](https://github.com/open-multi-agent/open-multi-agent/issues/116), [#117](https://github.com/open-multi-agent/open-multi-agent/issues/117), [#118](https://github.com/open-multi-agent/open-multi-agent/issues/118) by [@JackChen-me](https://github.com/JackChen-me))

- **CLI (`oma`).** New binary for shell and CI with `oma run`, `oma task`, `oma provider`, JSON-first output, and stable exit codes. Docs at `docs/cli.md`. ([#107](https://github.com/open-multi-agent/open-multi-agent/issues/107) by [@ibrahimkzmv](https://github.com/ibrahimkzmv))

- **`AgentConfig.customTools`.** Inject tool definitions at config time from the orchestrator. Bypasses preset/allowlist filtering but still respects `disallowedTools`. ([#109](https://github.com/open-multi-agent/open-multi-agent/issues/109), [#112](https://github.com/open-multi-agent/open-multi-agent/issues/112) by [@JackChen-me](https://github.com/JackChen-me))

- **`glob` built-in tool.** Find files by glob pattern, sorted by modification time. ([#102](https://github.com/open-multi-agent/open-multi-agent/issues/102) by [@ibrahimkzmv](https://github.com/ibrahimkzmv))

### Fixes

- **`AbortSignal` propagation.** Abort now reaches tool execution, the Gemini adapter, and the abort queue path. ([#104](https://github.com/open-multi-agent/open-multi-agent/issues/104) fixes [#99](https://github.com/open-multi-agent/open-multi-agent/issues/99), [#100](https://github.com/open-multi-agent/open-multi-agent/issues/100), [#101](https://github.com/open-multi-agent/open-multi-agent/issues/101), by [@JackChen-me](https://github.com/JackChen-me))

- **Error event propagation.** `AgentRunner.run()` now surfaces error events to callers. ([#103](https://github.com/open-multi-agent/open-multi-agent/issues/103) fixes [#98](https://github.com/open-multi-agent/open-multi-agent/issues/98), by [@JackChen-me](https://github.com/JackChen-me))

### Examples

- `examples/16-mcp-github.ts`: full MCP wiring
- `examples/17-minimax.ts`, `examples/18-deepseek.ts`, `examples/19-groq.ts`: provider quickstarts
- `examples/with-vercel-ai-sdk/`: Next.js + OMA `runTeam()` + AI SDK `useChat`

### Docs

- READMEs (EN/ZH) expanded: CLI, MCP, context strategies, tool output control, `customTools`. ZH caught up with EN on items that shipped in 1.1.
