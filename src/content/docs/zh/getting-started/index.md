三篇，按顺序读。它们带你从「什么都还没装」走到「一次跑完之后可以回头检查」的运行。

- [简介](/zh/getting-started/introduction/) —— `open-multi-agent` 是什么，目标优先的编排与手工连图的框架有何不同，以及这个差别在什么时候才重要。
- [快速开始](/zh/getting-started/quick-start/) —— 约五分钟跑通一张真实任务 DAG，无需 API key，然后用一行切换到真实模型。
- [选择运行方式](/zh/getting-started/three-ways-to-run/) —— `runAgent`、`runTeam` 还是 `runTasks`，取决于计划由谁拥有、以及任务图需要多可预测。

## 跑通之后

- [指南](/zh/guides/) —— 运行变成真实负载后会遇到的决定：编排控制、成本与预算上限，以及上生产前需要接好的部分。
- [参考](/zh/reference/) —— 逐页展开的运行时接口面：模型与工具、执行与调度、可观测性、评估，以及 `oma` 命令行。
- [示例](/zh/examples/) —— 按目标分组、可直接运行的配方，每个都附源码。
